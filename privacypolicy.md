Overview
This policy describes how data is handled when users interact with this Custom GPT that may call external APIs via Actions.

Data We Process

User inputs (prompts) and parameters necessary to fulfill the request (e.g., keywords, country/sector filters, date ranges).

URLs provided by the user (if any).

Purpose of Processing

To retrieve and summarize publicly available Project and Procurement information from official sources (EDCF, World Bank, ADB, AfDB) and provide analysis to the user.

Data Sharing (Third-Party APIs)
When Actions are executed, relevant parts of the user’s input may be transmitted to the following domains to retrieve data:

https://www.edcfkorea.go.kr

https://search.worldbank.org

https://data.adb.org

https://www.afdb.org

(Additional domains may be added if the Action configuration changes.)

Data Storage and Retention

The builder does not intentionally store user inputs in an external database outside of OpenAI’s platform.

If any logging is enabled in external infrastructure, it will be limited to operational troubleshooting and minimized.

Security
Reasonable administrative and technical measures are used to protect data transmitted to external endpoints.
